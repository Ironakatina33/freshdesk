PLANNING · BROUILLON PRIVÉ

Préparer la semaine, simplement.

Construisez un brouillon sur cet appareil, puis importez le fichier dans le planning officiel depuis un appareil autorisé. Rien n'est publié ici.

Important : cet outil ne synchronise pas les horaires et ne contacte pas le serveur du planning. Les noms et horaires restent uniquement en mémoire pendant que cette page est ouverte. Le fichier exporté contient des données de collègues : ne le laissez pas sur un PC partagé.

1. Ajouter les collègues

Un prénom ou nom complet par ligne. Seuls ceux que vous ajoutez apparaissent dans le brouillon.

    Les noms doivent correspondre à ceux du planning officiel pour que l'importation retrouve les bons profils. L'ajout n'envoie rien à GitHub.

    2. Remplir les horaires

    Touchez une case pour choisir service, repos ou CP.

    0 modification
    CollègueLunMarMerJeuVenSamDim
    Ajoutez un collègue pour commencer.

    Les cases « — » ne seront pas modifiées lors de l'importation. Le brouillon n'efface donc pas les horaires existants par défaut.

    3. Valider sur le planning officiel
    1. Récupérez le fichier .json sur un téléphone ou un appareil autorisé.
    2. Ouvrez City Équipe, identifiez-vous avec un profil manager, puis ouvrez « Gestion » → « Tableau de saisie ».
    3. Appuyez sur Importer un brouillon, choisissez le fichier et vérifiez la grille.
    4. Appuyez ensuite sur Enregistrer pour publier les modifications, après validation des éventuels conflits.

    Si vous ne pouvez pas transférer le fichier de manière autorisée, conservez le planning officiel comme seul moyen d'édition. Ne partagez pas un fichier de collègues sur des canaux non approuvés.
